# IELTS Vocabulary Training

Окремий застосунок для практики академічного вокабуляру IELTS Writing (Band 7–8), відокремлений від A1-застосунку з граматикою.

## Публікація на Vercel (новий, окремий проект)

1. Завантажте всі файли цього архіву у ваш репозиторій `IELTS-Vocabulary-Training` на GitHub (замінюючи те, що там уже є — старі файли з попередньої спроби).
2. На vercel.com натисніть **"Add New..."** → **"Project"** → **"Import Git Repository"** → оберіть **IELTS-Vocabulary-Training** (не `a1_tests_Target-English` — це інший, новий проект).
3. Нічого не змінюйте на екрані налаштувань → натисніть **"Deploy"**.
4. За хвилину отримаєте нове, окреме посилання (наприклад, `ielts-vocabulary-training.vercel.app`).

## Додавання нової теми

Кожна тема — новий `.json` файл у `data/exercises/`, за зразком наявних (`technology-flashcards.json`, `technology-matching.json`), + новий запис у `index.json`. Код змінювати не треба.
